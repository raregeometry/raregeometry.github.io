Troubleshooting and questions

Start with Tools > Photoworthy > Check Scene For Problems. It finds most setup mistakes and fixes many in one click. For "why this score?", use Tools > Photoworthy > Score Inspector.

Nothing happens when I press C #

  • Is there a Photo Camera in the scene, and does it have a Game Camera (or is your camera tagged MainCamera)?
  • Is the handheld camera enabled in the profile, and is Built In Input on under Keys?
  • With only the Input System active, the kit reads the same keys through it. If your project has neither input system active, call OpenHandheld from your own code.
  • Is the camera blocked (Blocked, CanOpen)? The Shot Refused event says why.

My subject is not recognised #

Open the Score Inspector and press Judge Game Camera. The subject is listed under Nearby but not counted with the reason:

Reason Fix
Too far Raise Max Distance in the profile's Recognition, or on the subject.
Too small Zoom in, or lower Min Picture Share.
Cut off More of it must be inside the picture. Lower Min In Frame to be more forgiving.
Hidden Something with a collider is in the way. Take see-through things (glass, leaves, trigger volumes are already ignored) off the Hiding Layers.
Not photographable The subject's Photographable box is off, or its object is disabled.

A subject with no renderer and no collider counts as a small box at its position; give it custom points instead.

The whole subject is in view but it says "Partly hidden" #

The check casts lines to points over the subject's bounds. For an odd shape (a tree with a thin trunk, an arch) some of those points sit in empty air behind other things. Switch the subject's Anchor Mode to Custom and place a few points on the parts that matter.

The score seems wrong for my kind of subject #

Use a scoring preset that suits it (Landmark for buildings, Small Object for clues) and give it to the subject asset as its Scoring Override. Switch off criteria that do not apply: the others share the points.

The photo mode has no blur, or the filters do nothing #

  • URP and HDRP: post processing must be on for the game camera (Rendering > Post Processing on the camera in URP).
  • Built-in: the kit adds its own image effect to the camera while a screen is open. A second camera drawn on top of the game camera can cover it.

My own HUD shows in photos #

Photos are a fresh render of the game camera, so screen-space overlay UI never appears. UI on a camera-space or world-space canvas does: list those objects under Storage > Hide In Pictures.

Photos are too large, or saving stutters #

JPG at 1080 is right for almost every game. PNG files are several times larger. Reading the picture back and writing the file run off the main thread; if a very large size with Smooth Edges still hitches on a weak device, lower the Size.

The album is empty after restarting #

Is Save To Disk on in the profile's Storage? Is the Storage Folder the same as last time (a different folder per save slot means a different album)?

Where are the photos? #

Application.persistentDataPath, in the profile's Storage Folder. On Windows that is under %USERPROFILE%\AppData\LocalLow\<company>\<product>\.

Can I use my own UI and still use the album and journal data? #

Yes. Switch off the screens you replace; the data, events and textures are all public. See Fit it into your game.

Does it need the Post Processing package, Cinemachine or TextMeshPro? #

No. There are no package dependencies. URP, HDRP and the Input System are used when present.

Does it work in 2D or with an orthographic camera? #

Recognition works with orthographic cameras and uses 3D colliders for the hidden check. For a 2D game, switch Check Hidden off (or put 3D colliders on what should hide things).

Can a photo be judged without making a picture? #

Yes. Switch Make Pictures off. The record of what was photographed is still made, requests still complete and the journal still fills.

Can players cheat by pausing in the photo mode? #

By default photo mode photos do not count for progress, exactly for this reason. Switch Counts For Progress on in the profile's Photo Mode if your game wants them to.

Does anything run when the camera is down? #

No. Subjects only register themselves when enabled; the viewfinder's checks run only while a camera screen is open.

How do I remove the demos? #

Delete the Samples folder.
